# models/ — pesos PyTorch locales (no versionados)

- Aquí puedes guardar `best.pt` para experimentos en Python (por ejemplo `models/current/best.pt`). Git lo ignora (`*.pt`).
- **El juego web NO usa esta carpeta.** El modelo activo del navegador está en
  `assets/models/michikembo/current/model.onnx` + `manifest.json`.
- Para instalar un modelo nuevo: `docs/COMO_CAMBIAR_MODELO.md`.
